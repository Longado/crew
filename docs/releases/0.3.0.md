# Crew 0.3.0 · 材料变行动

0.3.0 将首个试用入口收拢为：资料与当前项目生成带出处的建议，逐条采纳、暂缓或不采纳，再导出已采纳行动。仍为 MIT 许可的早期 Alpha。

## 变化

- Python 入口支持合成材料的离线预设演示，无需 Node、模型账号或私人任务库。
- JSON 项目清单提供当前项目范围，原有只读任务库入口继续兼容。
- 卡片保留材料与项目出处；逐条决定留存历史，导出 Markdown 或 JSON 中已采纳的建议，不执行行动。
- 中英文首页围绕完整材料流程组织。原项目现场的 Pages 样例明确标为旧版只读演示，工作台、负责人和管家入口保留。

## 安装与试用

macOS／Linux，Git 与 Python 3.9+：

```sh
git clone https://github.com/Longado/crew
cd crew
./bin/crew intake demo
```

接着按命令输出查看卡片、采纳 A1、导出，或使用 [README 的完整命令](../../README.md)。真实分析需要已订阅并登录的 Claude Code；材料与候选项目片段会发送给该服务。完整工作台另需 Node 22.18+、`npm ci`、`npm link`。

## 早期限制

目前读取 UTF-8 txt/md，目录不递归；PDF、音视频需先转文本。提示词与卡片主要为简体中文。演示是预设分析，不是模型效果证明；出处存在也不保证建议正确。没有自动收件箱监测或材料网页入口。原件不改，采纳不会创建任务或执行建议。

默认真实结果保存在 `~/.local-sensitive/crew-intake/`，演示在 `~/.local-sensitive/crew-intake-demo/`，可用 `--output` 更换；请自行管理权限与备份。详见 [材料说明](../INTAKE.md)。
